Characters

Cast notes for the recurring main-cast roles, researched by this project

  • Rumpole

    Horace Rumpole

    Actor(s):

    Leo McKern, across the entire run: the 1975 BBC Play for Today pilot (S00E01 in this project's numbering) and all seven numbered series (1978-1992).

    First appearance: S00E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance).

  • Hilda Rumpole

    "She Who Must Be Obeyed"

    Actor(s):
    • Joyce Heron: the 1975 pilot (S00E01) only. Weakly sourced (a single secondary review), and a fan discussion elsewhere disputes it; treat as uncertain pending a second source.
    • Peggy Thorpe-Bates: series 1-3 of the numbered run, 1978-1983 (S01-S03 in this project's folders). Her departure is reported as due to illness.
    • Marion Mathie: series 4-7, 1987-1992 (S04-S07). Took over after Thorpe-Bates left.
    First appearance: S00E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). Note the actor for that specific pilot appearance is the weakly-sourced "Joyce Heron" attribution above, not Thorpe-Bates.

  • Nick

    Rumpole's son

    Actor(s):

    David Yelland, for the 1975 pilot and the 1978-1979 numbered series (Series 1 and the start of Series 2), the only actor besides Leo McKern to carry over from the original BBC pilot into the regular series. No later recast has been confirmed.

    First appearance: S00E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance).

  • Henry

    chambers clerk, numbered series

    Actor(s):

    Jonathan Coy.

    First appearance: S01E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance).

  • George Frobisher

    fellow barrister

    Actor(s):

    Moray Watson.

    First appearance: S00E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He is identified just as "George" there and in S01E01; the fuller code name GEORGE FROBISHER first appears starting S01E04's speaker map.

  • Guthrie Featherstone

    barrister, later judge

    Actor(s):

    Peter Bowles, across the run (as barrister/Head of Chambers in the earlier series, later as Mr Justice Featherstone once elevated to the bench).

    First appearance: S01E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He does not appear in S00E01's speaker map.

  • Claude Erskine-Brown

    barrister

    Actor(s):

    Julian Curry, across the run.

    First appearance: S01E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He does not appear in S00E01's speaker map.

  • Phillida Trant / Erskine-Brown

    barrister

    Actor(s):

    Patricia Hodge, across the run (as "Miss Trant" in the earlier series, later as Phillida Erskine-Brown after marrying Claude Erskine-Brown, and eventually "QC").

    First appearance: S01E04, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). She does not appear in S00E01, S01E01, S01E02, or S01E03's speaker maps. The fuller name PHILLIDA TRANT first appears as a code name from S02E01 onward, and PHILLIDA ERSKINE BROWN from S03E04 onward (reflecting the character's marriage).

  • Sam Ballard

    Head of Chambers

    Actor(s):

    Peter Blythe, across the character's run.

    First appearance: S03E03, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He does not appear in any S00E01, S01, or S02 episode's speaker map covered so far.

  • Uncle Tom

    retired barrister in chambers

    Actor(s):

    Richard Murdoch, across the character's run.

    First appearance: S01E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He does not appear in S00E01's speaker map.

  • Judge Bullingham

    "The Mad Bull"

    Actor(s):

    Bill Fraser, as Judge Roger Bullingham, for Series 1-4 (1978-1987). Fraser died 9 September 1987, consistent with his last on-screen Bullingham appearance. A different, later "Judge Leonard Bullingham" appears in the story "Rumpole at Sea" (S06E04, 1991); no actor is confirmed for that later role, so treat any Bullingham appearance after Series 4 as a different, unconfirmed actor under the same character name and title.

    First appearance: S02E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He does not appear by name in S00E01 or S01's speaker maps (those have only a generic JD JUDGE code).

  • Liz Probert

    younger barrister

    Actor(s):

    Abigail McKern (Leo McKern's daughter), across the character's run.

    First appearance: S04E02, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). She does not appear in S00E01, S01, S02, or S03's speaker maps covered so far.

  • Diane

    chambers secretary/typist

    Actor(s):

    Maureen Darbyshire (spelled "Maureen Derbyshire" in some listings), appearing in six of the seven series of Rumpole of the Bailey as the Chambers Secretary at 1 Equity Court; cast listings spell her character's name "Diane"/"Dianne" inconsistently. Note this is a different role from Dot Clapton (played by Camille Coduri in later episodes), the other chambers support-staff character.

    First appearance: S02E04, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). She does not appear in S00E01, S01, or earlier S02 episodes' speaker maps covered so far.

  • Marigold Featherstone

    Guthrie's wife

    Actor(s):

    Joanna Van Gyseghem, across the show's full run, 1978-1992 (roughly 14 episodes).

    First appearance: S01E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). She does not appear in S00E01's speaker map. The fuller code names MRS FEATHERSTONE and MARIGOLD FEATHERSTONE appear from S01E05/S01E06 onward.

  • Fred Timson

    member of the Timson crime family

    Actor(s):

    Peter Childs played Fred Timson for 1978-79 (Series 1-2), then John Bardon played him for 1987-92 (Series 4-7). The sample below is drawn from S01E01 (1978), Childs's era, so the attribution stands; Fred Timson's recurrence in S02E06 ("Rumpole and the Age for Retirement," 1979) also falls inside Childs's range. The 1980-1983 window (Series 3) remains unresolved: no actor has been confirmed for Fred Timson in that window.

    First appearance: S01E01, based on this project's episode coverage so far (not necessarily the character's true first-broadcast appearance). He does not appear in S00E01's speaker map (the pilot's Timson-family client is a different character, "Oswald/Ossie Gladstone"). Fred Timson's own code (as distinct from other Timson-family members, e.g. Vi, Jim, Cyril, Tony, Dennis, Nigel Timson, each with their own codes in various episodes) also recurs later, e.g. S02E06, S04E06, S05E02.
