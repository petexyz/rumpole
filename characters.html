Characters

Cast notes for the recurring main-cast roles, researched by this project

  • Rumpole

    Horace Rumpole

    Actor(s):

    Leo McKern, across the entire run: the 1975 BBC Play for Today pilot (S00E01 in this project's numbering) and all seven numbered series (1978-1992).

    First appearance:

    S00E01 (code R / Rr / Rv in rumpole-s00e01-speakers.txt; the three codes distinguish plain dialogue, recited verse, and voice-over narration, all still Leo McKern). This reflects only what has been transcribed into screenplay/ so far, not necessarily Rumpole's true first-broadcast appearance.

  • Hilda Rumpole

    "She Who Must Be Obeyed"

    Actor(s):
    • Joyce Heron: the 1975 pilot (S00E01) only. Weakly sourced (a single secondary review), and a fan discussion elsewhere disputes it; treat as uncertain pending a second source.
    • Peggy Thorpe-Bates: series 1-3 of the numbered run, 1978-1983 (S01-S03 in this project's folders). Her departure is reported as due to illness.
    • Marion Mathie: series 4-7, 1987-1992 (S04-S07). Took over after Thorpe-Bates left.
    First appearance:

    S00E01 (code H in rumpole-s00e01-speakers.txt). This reflects only what has been transcribed into screenplay/ so far. Note the actor for that specific pilot appearance is the weakly-sourced "Joyce Heron" attribution above, not Thorpe-Bates.

  • Nick

    Rumpole's son

    Actor(s):

    David Yelland. Confirmed for the 1975 pilot (S00E01) and, per IMDb's episode credits, for the 1978-1979 numbered series (series 1 and the start of series 2, i.e. this project's S01 and likely S02), reported as the only actor besides Leo McKern to carry over from the original BBC pilot into the regular series. No source found distinguishing a later recast; Nick's code does not appear to recur in this project's transcripts past S02, so no later-era casting question currently arises. Treat any appearance beyond S02 as unconfirmed if more episodes are transcribed later.

    First appearance:

    S00E01 (code N in rumpole-s00e01-speakers.txt). This reflects only what has been transcribed into screenplay/ so far, not necessarily Nick's true first-broadcast appearance (he also appears, same code family, in S01E01, S01E03, and under code NK in S02E06/S02E07).

  • Judge Bullingham

    "The Mad Bull"

    Actor(s):

    Bill Fraser. Prior research for this project had this actor as "unconfirmed"; a follow-up web search (2026-11-23) found IMDb credits and a Daily Mail feature both naming Bill Fraser as Judge Roger Bullingham for 1978-1987 (this project's S01-S04), i.e. this project's S00E01-contemporaneous-through-S04 window. A second follow-up search (2026-11-23) confirms Fraser died 9 September 1987 (Wikipedia), which fits his last on-screen Bullingham credit and rules out his continuing into later series. A different, later "Judge Leonard Bullingham" appears in the story "Rumpole at Sea," which is also a TV episode, S06E04 in this project's numbering (broadcast 1991, per TVmaze/PBS listings). No actor has been found for Leonard Bullingham: IMDb, TMDB, and Wikipedia's main Rumpole article give no cast credit for that name, and TVmaze's episode cast page could not be read (it is blocked behind a JavaScript challenge). This project's own transcribed screenplay (through S07E05) has no BULLINGHAM speaker code outside S04E06, so no built transcript has yet put this recast question to the test. Treat any Bullingham appearance after S04 as a different, still-unconfirmed actor under the same character name/title.

    First appearance:

    S02E01 (code JD / = JD JUDGE BULLINGHAM in rumpole-s02e01-speakers.txt). He does not appear by name in S00E01 or S01's speaker maps (those have only a generic JD JUDGE code). This reflects only what has been transcribed into screenplay/ so far.

  • Fred Timson

    member of the Timson crime family

    Actor(s):

    Resolved by a follow-up web search, 2026-11-23: Peter Childs played Fred Timson for 1978-79 (Series 1-2), then John Bardon played him for 1987-92 (Series 4-7). This is not actually the discrepancy earlier research took it for: IMDb's own full series cast list (tt0078680) carries both actors as separate entries, each with its own year range, on the same page, rather than disagreeing with each other about one era. The original "episode-level vs. series-level" framing came from only noticing one of the two entries on different passes through the credits.

    The sample below is drawn from S01E01 (1978), which is Peter Childs's era, so the attribution stands. Fred Timson's recurrence in S02E06 ("Rumpole and the Age for Retirement," 1979) also falls inside Childs's range. The 1980-1983 window (Series 3) is not covered by either actor's listed year range and remains genuinely unresolved: no actor has been found for Fred Timson in Series 3.

    First appearance:

    S01E01 (code FT / = FT FRED TIMSON in rumpole-s01e01-speakers.txt). He does not appear in S00E01's speaker map (the pilot's Timson-family client is a different character, "Oswald/Ossie Gladstone"). This reflects only what has been transcribed into screenplay/ so far. Fred Timson's own code (as distinct from other Timson-family members, e.g. Vi, Jim, Cyril, Tony, Dennis, Nigel Timson, each with their own codes in various episodes) also recurs later, e.g. S02E06, S04E06, S05E02.
